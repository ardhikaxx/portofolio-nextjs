# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x     | ✅ |
| < 1.0   | ❌ |

## Reporting a Vulnerability

If you find a security vulnerability, please report it to:

- **Email**: [yanuarardhika@gmail.com](mailto:yanuarardhika@gmail.com)
- **GitHub Issues**: [github.com/ardhikaxx/portofolio-nextjs/issues](https://github.com/ardhikaxx/portofolio-nextjs/issues)

Please do not open a public issue for critical security vulnerabilities. I will respond within 48 hours and work on a fix as soon as possible.
